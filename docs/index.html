04 / ONE FIXED INDEX, EVERY THRESHOLD

Discard fewer. Recover more.

Lowering the shared-bit threshold makes a nested candidate set. Exact rescoring with the same score/id ordering means every admitted canonical exact top-k neighbor survives into the result. Recall is therefore monotone for this fixed index and k, including ties under the declared id rule.

Solid: observed recall in this fixed index. Dotted: expected recall over independent isotropic random-plane rebuilds. They are different quantities.

ThresholdCandidatesRecallExpected countExpected recall

Marginal agreement is p =1-acos(cosine)/pi. A nonzero pair's shared-bit count is Binomial(bits,p) under iid isotropic planes. Expected candidate count sums admission probabilities; expected recall averages them over canonical exact top-k. Candidate events share planes and need not be independent. No binomial law for total candidate count is claimed. Zero-vector angular values are shown as undefined, not filled with p=.5.

06 / CONTRACT AND CONTROLS

A perfect self-match can hide a miss.

The two retained self-retrieval controls use the same two vectors, query, 8 Gaussian planes and strict threshold. Including the query id gives recall 1. Excluding it gives recall 0. This is an illustrative protocol difference, not a general performance claim. Leave-one-id-out is also not a held-out benchmark; duplicate vectors may remain.

The original 31 tests, corpus, demo, seeded protocol and 1.0 recall@3 result remain visible. New checks cover scale-safe extreme magnitudes, duplicate/nonfinite rejection, full-precision recall gates, leave-one-id-out, rational binomial tails, full-circle angular agreement,1200 seeded rebuilds and an independent browser recomputation.

This is still a signature scan: O(N) stored signature comparisons plus query projections and candidate rescoring. Rescored fractions exclude intentionally removed ids. No latency, embedding quality, statistical confidence interval, production scaling or new LSH algorithm is claimed. Finite arithmetic can move a near-zero projection across a sign boundary. Theory assumes ideal iid isotropic nonzero random planes and is not conditional on these fixed displayed planes or valid for arbitrary edited plane sets.
